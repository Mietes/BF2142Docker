# BF2142 Remaster — свой сервер

Свой сервер для **Battlefield 2142** с модом **Project Remaster v17**: замена давно выключенных сервисов
EA/GameSpy (вход в аккаунт, солдаты, звания, анлоки, награды, статистика в Штабе, список серверов) и
игровой сервер с сохранением прогресса.

- Развернуть на Linux-сервере (Docker) — **[DEPLOY.md](DEPLOY.md)**.
- Запустить всё на одном ПК с Windows, утилиты, установщик для игроков — [Backend/README.md](Backend/README.md).

## Из чего состоит

```
 Игрок (BF2142 + Remaster, наш установщик)
   │  вход, солдаты ─────────► FESL      TCP 18300  ┐
   │  профиль GameSpy ───────► GPCM      TCP 29900  │
   │  звания, анлоки, Штаб ──► статистика TCP 80    ├─ бэкенд (Python, контейнер backend)
   │  список серверов ───────► мастер    TCP 28910  │   + веб-админка TCP 8142 (только localhost)
   │                           мастер    UDP 27900  ┘          ▲
   │                                                           │ итоги раунда, баны, админы
   │  игра ──────────────────► игровой сервер UDP 17567, 29900 ┘  (подписаны общим секретом)
                               (Linux 1.51 + Remaster, контейнер gameserver)
```

**Бэкенд** (`Backend/bf2142srv`, Python 3.14, база SQLite):

| Модуль | Что делает |
|---|---|
| `fesl.py` | вход/регистрация, солдаты; SSLv3 + RC4 через tlslite-ng (игра 2006 года другого не понимает) |
| `gpcm.py` | профиль GameSpy: по тикету FESL игрок получает ID солдата для игрового сервера |
| `stats_http.py` | `*.aspx` для игры: звания, анлоки, награды, Штаб, таблица лидеров, проверка игрока сервером |
| `master.py` | список серверов: QR2 (heartbeat серверов) + Server Browser с шифрованием enctypeX |
| `servers.py` | запросы игровых серверов: итоги раунда, список админов и банов, бан из игры (HMAC-подпись) |
| `rounds.py`, `progression.py`, `awards.py` | опыт за раунд, звания, очки анлоков, условия наград |
| `admin_web.py` + `admin_ui.html` | веб-админка: игроки, звания, анлоки, награды, баны, пароли |
| `db.py`, `config.py` | база (аккаунты, солдаты, статистика, раунды, награды, баны) и настройки |

**Игровой сервер**: официальный Linux-сервер BF2142 1.51 (сборка 1.10.112.0) + серверная часть Remaster.
Адреса GameSpy в бинарнике перенаправлены на бэкенд (`Backend/tools/patch_server.py`), в его Python
добавлены наши модули (`Backend/gameserver`):

- `selfhost.py` — в конце раунда отправляет итоги игроков бэкенду (подпись HMAC-MD5 общим секретом);
- `selfhost_admin.py` — команды админов в чате (`!kick`, `!ban`, `!unban`, `!help`), кик забаненных,
  кик за бездействие.

**Клиент**: игрокам нужна BF2142 1.51 с Remaster v17 и наш патч Штаба. Установщик собирает
`Backend/tools/build_release.py` (Inno Setup): в мастере игрок вписывает адрес сервера, установщик делает
копию exe с этим адресом (`BF2142_selfhost.exe`), прописывает реестр и ставит ярлык.

## Прокачка

- Солдат начинает с нуля. Опыт за раунд считает игровой сервер; бэкенд добавляет бонусы (победа +20%,
  первая победа за сутки ×2, игры с ботами ×0,5), выдаёт звания по таблице игры и очки анлоков.
- 126 наград (значки, медали, ленты, значки отличия) по условиям из игры; за каждую — бонусный опыт.
- Звания 41–43 — топ недели по опыту среди генералов.
- Всё настраивается в `config.toml` / `.env`; подробности — в [Backend/README.md](Backend/README.md).

## Безопасность

- Итоги раундов и админ-команды принимаются только с подписью общим секретом (`BF2142_SERVER_SECRET`).
- Пароли хранятся как PBKDF2-SHA256. Сам вход у игры — устаревший SSLv3/RC4: игрокам стоит придумать
  для сервера отдельный пароль.
- Веб-админка слушает только localhost хоста (снаружи — через ssh-туннель).
- Имена аккаунтов и солдат — только латиница и цифры (другие символы ломали протоколы игры).

## Структура репозитория

```
Backend/                бэкенд: код, утилиты, тесты, установщик для игроков (Windows)
  bf2142srv/            сервисы бэкенда
  gameserver/           наши Python-модули для игрового сервера
  tools/                утилиты: патчи exe, сборки, аккаунты, тесты
  installer/, kit/      установщик игры и комплект для уже установленной игры
docker/gameserver/      образ игрового сервера: Dockerfile, запуск, настройки по умолчанию
docker-compose.yml      бэкенд + игровой сервер
.env.example            настройки развёртывания
```

Файлов игры и игрового сервера (EA, Project Remaster) в репозитории нет — они передаются отдельным
архивом (см. [DEPLOY.md](DEPLOY.md)). Project Remaster — работа его авторов, распространяется с их
разрешения.

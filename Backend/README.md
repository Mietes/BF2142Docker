# Свой бэкенд для Battlefield 2142

Заменяет мёртвые серверы EA/GameSpy: вход в аккаунт, солдаты, звания, анлоки и статистика.
Два режима анлоков (`config.toml` → `[unlocks] mode`):

- `progression` — солдат начинает с нуля, получает опыт за раунды, звания дают очки анлоков;
- `all` — всё открыто сразу.

## Из чего состоит

| Сервис | Порт | Что делает |
|---|---|---|
| FESL | TCP 18300 (SSLv3) | аккаунты, солдаты, вход |
| GPCM | TCP 29900 | профиль GameSpy (ID солдата для игрового сервера) |
| Статистика | TCP 80 (HTTP) | ранги, анлоки, BFHQ, приём итогов раунда |
| Доступность | UDP 27900 | ответ «GameSpy работает» |

Данные — в `data\bf2142.sqlite3`, журнал — `data\backend.log`.

## Папки

```
C:\Games\BF2142 Remaster\     — игра: BF2142 1.51 + Project Remaster v17 + патч Штаба,
                                BF2142_selfhost.exe (копия exe с адресом бэкенда), launch_bf2142.ps1
C:\Games\BF2142 Server\
    start_all.bat             — запуск бэкенда и игрового сервера
    Backend\                  — этот бэкенд (настройки config.toml, база data\, утилиты tools\)
    GameServer\               — дедик-сервер BF2142 1.51 с Remaster (start_server.bat)
```

Пути к игре и серверу утилиты берут из `config.toml` → `[paths]`.

## Быстрый старт (всё на одном ПК)

1. В `config.toml` проверь `public_host` (для одного ПК — `127.0.0.1`), `mode` и `[paths]`.
2. Один раз подготовь клиент и сервер (из папки `Backend`):
   ```
   .venv\Scripts\python.exe tools\patch_client.py
   .venv\Scripts\python.exe tools\build_hq_patch.py
   .venv\Scripts\python.exe tools\install_server.py
   ```
   - `patch_client.py` делает **копию** `BF2142_selfhost.exe` с адресом бэкенда. Оригинальный `BF2142.exe` не меняется.
   - `build_hq_patch.py` ставит в Remaster патч страницы поощрений и исправленную локализацию.
   - `install_server.py` патчит `GameServer\BF2142_w32ded.exe` (оригинал — `*.orig`), ставит модули
     итогов раунда и администрирования (с секретом для подписи) и создаёт `GameServer\start_server.bat`.
     Настройки сервера — `GameServer\mods\Project_Remaster_v17\Settings\selfhost.con`, карты —
     `selfhost_maplist.con` там же.
3. Запусти `C:\Games\BF2142 Server\start_all.bat` (бэкенд и сервер). Windows может спросить про доступ
   к сети для Python — разреши (для игры по сети — обязательно).
4. Запусти игру ярлыком «BF2142 Remaster», войди с **любым новым** логином (латиница и цифры) и паролем —
   аккаунт создастся сам (`auto_register`), создай солдата и заходи на сервер.

Автовход для тестов:
`BF2142_selfhost.exe +modPath mods/Project_Remaster_v17 +eaAccountName ЛОГИН +eaAccountPassword ПАРОЛЬ +soldierName СОЛДАТ +fullscreen 0`

## Игра с друзьями

1. `public_host` = адрес, по которому друзья достанут твой ПК: внешний IP (нужен проброс портов) или
   адрес в VPN вроде Radmin VPN / ZeroTier (проще, ничего пробрасывать не надо).
2. Перезапусти бэкенд и заново выполни `patch_client.py` и `install_server.py` — они возьмут новый адрес.
3. Друзьям — установщик игры (см. ниже), адрес они впишут в мастере (или вшей его через `--address`).
4. Проброс портов (если без VPN): TCP 18300, 29900, 80, 28910 (список серверов); UDP 27900 — бэкенд;
   UDP 17567, 29900 — игровой сервер (и UDP 55123-55125, если включён голосовой чат). В `config.toml`
   поставь `bind = "0.0.0.0"`. Нужен «белый» IP: за CGNAT провайдера проброс не работает — тогда VPN.

### Смена адреса сервера — что где менять

1. `config.toml`: `[network] bind = "0.0.0.0"`, `public_host = "<адрес для игроков>"`
   (внешний IP или IP в Radmin VPN `26.x.x.x`).
2. Перезапуск: закрыть окна бэкенда и сервера, запустить `C:\Games\BF2142 Server\start_all.bat`.
   Windows спросит про доступ к сети для Python и BF2142_w32ded — разрешить.
3. Свою игру и игровой сервер на этом ПК не трогать: они ходят на `127.0.0.1`, а мастер-сервер
   отдаёт хозяину локальный адрес сервера, остальным — `public_host`.
4. Игрокам — тот же адрес в мастере установщика (страница «Адрес сервера»). Сменился адрес —
   они запускают `setup.exe` ещё раз в ту же папку. Можно вшить адрес в установщик:
   `build_release.py --address <адрес>`.

## Прокачка

- Опыт (`crpt`) за раунд считает игровой сервер, бэкенд суммирует его и выдаёт звания по таблице
  из игры (звание 40 = 57 700 опыта). Повышение показывается в игре.
- Каждое звание даёт `credits_per_rank` очков анлоков (плюс `start_credits` новому солдату).
  Анлок покупается в меню игры; уровни в ветке открываются по порядку.
- `[stats] count_coop` — засчитывать ли игры с ботами, `min_round_seconds` — минимум времени в бою.
- Награды (значки, медали, ленты, значки отличия) проверяет бэкенд по итогам раунда, условия —
  из `bf2142srv/res/awards_backend.con` (`bf2142srv/awards.py`). За каждую — бонусный опыт из `[awards]`.
  Значки и ленты даются один раз, медали и значки отличия — не чаще раза за раунд.
- `[content] northern_strike` — выдавать всем дополнение Northern Strike.

## Установщик игры для игроков

```
.venv\Scripts\python.exe tools\build_release.py [--address IP[:порт]] [--version 1.0]
```

Собирает обычный установщик на Inno Setup (как у сборок игры): `setup.exe` + `setup-1.bin`,
`setup-2.bin` … (~5,3 ГБ) и `SHA256SUMS.txt` в папке `C:\Games\BF2142 Build`. Нужен Inno Setup 6.
Внутри — игра из `[paths] game` целиком (1.51 + Remaster v17 + патч Штаба). Мастер (русский/английский):
папка → язык игры (русский/английский/немецкий) → адрес сервера (с `--address` уже вписан) → установка.
Установщик сам прописывает игру в реестр (путь, язык, CD-ключ, если его нет), делает
`BF2142_selfhost.exe` с адресом, выключает сглаживание в профилях и ставит ярлык «BF2142 Remaster»
(запуск exe напрямую, без PowerShell). Удаление — через «Приложения». Смена адреса — повторный
запуск `setup.exe` в ту же папку (неизменённые файлы не перезаписываются).
Тихая установка для проверки: `setup.exe /VERYSILENT /DIR=... /ADDRESS=1.2.3.4 /GAMELANG=ru|en|de`.
Сценарий — `installer\bf2142.iss`, памятка из мастера — `installer\README.txt`.

## Комплект для уже установленной игры

```
.venv\Scripts\python.exe tools\build_kit.py [--address IP[:порт]]
```

Собирает `dist\BF2142_Selfhost_Kit\` и `dist\BF2142_Selfhost_Kit.zip` (~9 МБ) — его и раздавать.
Игроку нужен BF2142 1.51 из нашей сборки и Project Remaster v17: установщик сверяет exe и версию
Remaster и откажется работать с другими. Игрок распаковывает архив, вписывает адрес в `server.txt`
(или установщик спросит; с `--address` адрес уже вписан) и запускает `INSTALL.bat`:

1. копия `BF2142.exe` -> `BF2142_selfhost.exe` с адресом сервера (оригинал не меняется);
2. патч Штаба и исправленная локализация Remaster (с резервной копией);
3. лаунчер `launch_bf2142.ps1` и ярлык «BF2142 Remaster» на рабочем столе;
4. сглаживание выключается в профилях (лаунчер делает это и перед каждым запуском).

Адрес сервера сменился — игрок снова запускает `INSTALL.bat`. `UNINSTALL.bat` возвращает игру как было.
Порт нужен, только если статистика не на 80-м. После изменения патча Штаба (`build_hq_patch.py`)
комплект нужно пересобрать. Секрет сервера, база и `config.toml` в комплект не попадают.

## Администрирование

- **Веб-админка**: http://127.0.0.1:8142/ (ярлык `C:\Games\BF2142 Server\BF2142 Админка.url`), работает,
  пока запущен бэкенд, и открывается только на этом компьютере (`[admin] web_port`, 0 — выключить).
  Список игроков с поиском; у игрока — звание и опыт, анлоки по веткам, награды (выдать/снять),
  бан и разбан (в том числе по IP), смена пароля, переименование, удаление солдата, последние раунды
  и вся статистика с правкой. Вкладка «Баны» — действующие баны. Вкладка «Сервер» — состояние игрового
  сервера и игроки онлайн (кик), смена карты, сообщение в чат, настройки (огонь по своим, тикеты, время,
  автобаланс, голосования, пароль, название…) и ротация карт с проверкой режимов и размеров. Игровой
  сервер забирает их раз в 30 секунд (`/selfhost/status` + `/selfhost/serverconfig`). Изменения сразу в базе, игрок
  увидит их после перезахода. Код — `bf2142srv/admin_web.py` и `admin_ui.html`.
- **Имена** аккаунтов и солдат: только латинские буквы и цифры, от 3 до 16 символов. Остальное
  бэкенд отклоняет, игра показывает «Недопустимое название учетной записи…» (текст правит
  `tools/build_hq_patch.py`). Старые имена продолжают работать.
- **Админы** — солдаты из `config.toml` → `[admin] admins`. Команды пишутся в чат игры
  (в любой: общий, командный, отделения):
  - `!kick ИМЯ [причина]` — кик;
  - `!ban ИМЯ [30m|12h|7d|perm] [причина]` — бан аккаунта и кик, без срока — навсегда;
  - `!unban СОЛДАТ` — разбан;
  - `!help` — подсказка.

  ИМЯ можно писать частью ника (`!kick bob`), если она подходит одному игроку. Админа кикнуть
  нельзя. Ответы и объявления в чате — на английском (у европейских клиентов нет кириллицы).
- **Баны** — на уровне аккаунта: забаненный не может войти (игра пишет «Учетная запись
  заблокирована администрацией сервера»), а тех, кто уже на сервере, игровой сервер кикает
  в течение двух минут. Из консоли:
  `accounts.py ban ЛОГИН|СОЛДАТ [срок] [причина] [--ip]`, `accounts.py unban …`, `accounts.py bans`.
  `--ip` банит ещё и IP последнего входа (с него не войти и не завести новый аккаунт) — осторожно,
  у провайдеров с общим IP заденет соседей.
- **Кик за бездействие**: `[admin] idle_kick_minutes` (по умолчанию 5, 0 — выключен). За минуту
  до кика игроку приходит предупреждение. Командира и админов не трогает.
- **Автобаланс и наказание за убийство своих** — встроенные скрипты сервера, настройки в его
  `ServerSettings.con`: `sv.autoBalanceTeam 1`, `sv.tkPunishEnabled 1`, `sv.tkNumPunishToKick 3`
  (в Remaster включены по умолчанию).
- **Забыл пароль**: почты нет, поэтому вручную. Игрок пишет админу логин или имя солдата,
  админ выполняет `accounts.py passwd ЛОГИН|СОЛДАТ НОВЫЙ_ПАРОЛЬ` и сообщает пароль игроку.
  «Запомненный» вход на старом пароле при этом сбрасывается.
- **Защита итогов раунда**: игровой сервер подписывает итоги и админ-команды секретом из
  `data\server_secret.txt` (создаётся сам; `install_server.py` прописывает его в модуль сервера),
  неподписанные и повторные запросы бэкенд отклоняет. Этот файл никому не отдавать и в комплект
  для игроков не класть. Если сменил секрет — перезапусти бэкенд и снова выполни
  `install_server.py`. `[servers] allowed_ips` дополнительно ограничивает адреса игровых серверов.

## Утилиты

```
.venv\Scripts\python.exe tools\accounts.py list                       — аккаунты и солдаты
.venv\Scripts\python.exe tools\accounts.py add ЛОГИН ПАРОЛЬ СОЛДАТ    — создать аккаунт с солдатом
.venv\Scripts\python.exe tools\accounts.py stats СОЛДАТ               — звание, опыт, анлоки
.venv\Scripts\python.exe tools\accounts.py passwd ЛОГИН|СОЛДАТ ПАРОЛЬ — сменить пароль
.venv\Scripts\python.exe tools\accounts.py ban ЛОГИН|СОЛДАТ [7d] [причина] [--ip] — бан
.venv\Scripts\python.exe tools\accounts.py unban ЛОГИН|СОЛДАТ         — разбан
.venv\Scripts\python.exe tools\accounts.py bans                       — действующие баны
.venv\Scripts\python.exe tools\selftest.py                            — проверка запущенного бэкенда
.venv\Scripts\python.exe tools\test_progression.py                    — тесты прокачки (без сети)
.venv\Scripts\python.exe tools\test_awards.py                         — тесты наград (без сети)
.venv\Scripts\python.exe tools\test_admin.py                          — тесты подписи и банов (без сети)
.venv\Scripts\python.exe tools\test_server_admin.py                   — тесты админ-модуля сервера (без сети)
```

## Пока не сделано

- Награда 416 (захват базы ПАК в Assault Lines): сервер не сообщает такого события.

## Откуда что взято

- Таблица званий/наград для `getbackendinfo` и колонки статистики — из
  [bf2142stats_emu](https://github.com/maiorBoltach/bf2142stats_emu) (GPL-2).

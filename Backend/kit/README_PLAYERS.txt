BATTLEFIELD 2142 — ПАМЯТКА ИГРОКУ / PLAYER NOTES
==================================================

РУССКИЙ

Установка
- Нужны: Battlefield 2142 версии 1.51 из нашей сборки и мод Project Remaster v17.
- Распакуй комплект куда угодно (удобно — прямо в папку игры).
- Впиши адрес сервера в server.txt (или установщик спросит сам) и запусти INSTALL.bat.
  Если игра в Program Files, Windows попросит права администратора — это нормально.
- Играй через ярлык «BF2142 Remaster» на рабочем столе. Вариант «(borderless)» —
  окно без рамки: Alt+Tab мгновенный, но картинка чуть мягче.
- При первом входе введи новый логин и пароль — учетная запись создастся.
- Сервер сменил адрес? Впиши новый в server.txt и снова запусти INSTALL.bat.
- Удалить всё и вернуть игру как было: UNINSTALL.bat. Оригинальный BF2142.exe комплект
  не меняет: для сервера делается копия BF2142_selfhost.exe.

1. Пароль. Игра 2006 года шифрует вход устаревшим способом, его можно подслушать в сети.
   Придумай для сервера отдельный пароль: НЕ тот, что от почты, Steam, банка и т. п.
2. Имена. Логин и имя солдата — только латинские буквы и цифры, от 3 до 16 символов
   (например Ivan2142). Пробелы, дефисы, подчёркивания и кириллица не принимаются.
3. Забыл пароль? Почтой он не восстанавливается. Напиши администратору сервера
   свой логин или имя солдата — он выдаст новый пароль.
4. Графика. Сглаживание (Antialiasing) в настройках игры держи выключенным (Off):
   с ним мир становится чёрным, а Alt+Tab роняет игру.
5. Не удаляй видеоролики из папок mods\...\Movies — без них ломается Alt+Tab.
6. Правила: за убийства своих сервер наказывает и кикает, за бездействие (5 минут) кикает,
   читеров банят.

ENGLISH

Installation
- Requires Battlefield 2142 1.51 from our game build and the Project Remaster v17 mod.
- Extract the kit anywhere (the game folder is a good place).
- Put the server address into server.txt (or the installer will ask) and run INSTALL.bat.
  If the game is in Program Files, Windows will ask for administrator rights.
- Play with the "BF2142 Remaster" desktop shortcut. "(borderless)" runs in a frameless
  window: instant Alt+Tab, slightly softer picture.
- On the first login enter a new account name and password - the account will be created.
- Server address changed? Put the new one into server.txt and run INSTALL.bat again.
- UNINSTALL.bat removes everything. The kit never changes BF2142.exe itself: it makes
  a copy, BF2142_selfhost.exe.

1. Password. This 2006 game protects the login with outdated encryption that can be sniffed.
   Use a separate password for this server, NOT the one from your e-mail, Steam, bank, etc.
2. Names. Account and soldier names may contain only Latin letters and digits, 3 to 16
   characters (e.g. Ivan2142). Spaces, dashes, underscores and non-Latin letters are rejected.
3. Forgot your password? There is no e-mail recovery. Send your account or soldier name to
   the server admin and you will get a new password.
4. Graphics. Keep Antialiasing Off in the game settings: with it the world renders black
   and Alt+Tab crashes the game.
5. Do not delete the videos in mods\...\Movies: Alt+Tab breaks without them.
6. Rules: teamkillers get punished and kicked, idle players are kicked after 5 minutes,
   cheaters are banned.
